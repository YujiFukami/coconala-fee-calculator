# ココナラ見積・手取り・予算逆算ツール

ココナラ通常サービス向けの参考計算Webアプリです。

## 起動方法

`index.html` をブラウザで開くと動作します。バックエンドやビルド手順は不要です。

入力値や設定を変更すると自動計算されます。金額欄には `+100`、`+1,000`、`+10,000` などの増減ボタンを用意しています。
数字ボタン、`1字消す`、`全消去` でも入力できるため、マウスやスマートフォンだけでも金額を調整できます。

## ファイル構成

- `index.html`: 画面構造
- `styles.css`: レイアウトと見た目
- `js/calculator.js`: 計算ロジック
- `js/app.js`: 画面操作と描画
- `coconala_fee_calculator_requirements.md`: 要件定義
- `ワイヤーフレーム案.png`: 画面案

## 主な機能

- 見積額から、お客様支払総額と出品者手取りを計算
- お客様支払上限額から、提示可能な最大見積額を逆算
- 目標手取り額から、必要な最小見積額を逆算
- 消費税あり / なし、料率、端数処理の切り替え
- 入力の起点になっている金額行を内訳表で強調表示
- 横向き内訳バーで、お客様支払総額とサービス価格の内訳を可視化
- 結果と説明文のコピー
- Softex Celware公式サイト、ココナラ出品者ページへのリンク

## 検証観点

```powershell
node --check js\calculator.js

node tests\calculator.test.js
```

- 見積額 50,000円 / 消費税あり
- 見積額 50,000円 / 消費税なし
- お客様支払上限 200,000円 / 消費税あり
- お客様支払上限 200,000円 / 消費税なし
- 目標手取り額からの逆算
- スマートフォン幅での1カラム表示

## 注意

本ツールは公式ヘルプの料率をもとにした参考計算です。最終金額はココナラ画面で確認してください。

## 公式ヘルプとの照合メモ

2026-05-29時点で、ココナラ公式ヘルプ上の通常サービス向け説明と照合しています。

- 購入者側: 1回のお支払いごとの価格に対してサービス手数料5.5%
- 出品者側: 通常サービス・見積り相談などは販売時手数料22%
- 課税事業者登録がある場合: 消費税を含むサービス価格から販売時手数料22%
- 端数処理: 購入者サービス手数料・販売時手数料ともに、小数点第一位を四捨五入
